# 来源与接入范围

由用户提供的 `radial-timeline` 项目迁移，源目录日期为 2026-10-18。原项目依赖 React、Tailwind CSS 和 Framer Motion；参考效果为 [Devouring Details — Radial Timeline](https://devouringdetails.com/)。此记录不额外声明来源项目的作者或许可证。

保留来源的 `RadialTimeline.tsx` 中 TickLine、EventLabel、MotionValue 坐标计算、节点展开大弧形、120 个刻度、动画曲线与展开时长。按用户后续要求，删除滚动旋转、循环与吸附；返回收回圆环并恢复节点焦点。

全屏布局改为可测量的局部容器，不锁定 body。测量与展开动画生命周期拆至同目录 Hook，补充卸载清理、减少动态与返回焦点；颜色继承博客主题。

文章接入将节点及详情改为调用方输入；移除 14 条历史演示数据和按年份间隔分配角度的算法。业务组件 `features/articles/components/article-timeline/` 维护精选文章的 slug 与短标题，复用现有文章的标题、摘要、日期与正文路由。当前四个精选节点按发布日期顺时针排序，采用非等距编辑排版，保留无标签弧段；角度不编码真实日期间隔。节点显示短标题和年月，展开预览并提供“阅读全文”，圆心保留现有时钟。原 120 刻度与极坐标动画继续使用；月份计数与年份切换原型已移除。原目录未修改。

按用户最新要求增加秒数驱动：普通模式初始对齐真实秒数，每秒 6° 匀速顺时针运动，文字保持正向；悬浮标题时暂停，移开从原角度继续，触摸不触发暂停。展开详情时停止自动转动，返回对齐当前秒数并恢复；减少动态保持静止。动画帧与补间在暂停、切换和卸载时清理，数字时钟按整秒边界独立刷新。
